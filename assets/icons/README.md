# Ícone do WhatsApp

`whatsapp.svg` foi obtido do [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/whatsapp.svg), sem alteração da geometria. A licença CC0 do projeto está em `LICENSE-simple-icons.md`. A marca WhatsApp pertence ao seu titular; a inclusão do ícone identifica apenas o canal de contato solicitado.

No botão flutuante, o CSS apresenta o ícone em branco sobre verde. O arquivo é local e não requer scripts, fontes de ícones ou chamadas externas.
